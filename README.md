# AnimeTV - Приложение для Android TV

Готовый проект приложения для просмотра аниме на Android TV (с поддержкой пульта ДУ, экрана выбора серий и HLS-видеоплеера Media3 ExoPlayer).

## Как получить готовый `.apk` файл:

### Вариант 1: Без установки программ (в облаке через GitHub Actions)
В проект уже встроен конфигурационный файл `.github/workflows/build_apk.yml`.
1. Создайте новый репозиторий на [GitHub](https://github.com/) и загрузите в него содержимое этого архива.
2. Перейдите во вкладку **Actions** в вашем репозитории.
3. Сборка запустится автоматически (либо нажмите **Build Android TV APK** -> **Run workflow**).
4. Через 2–3 минуты внизу страницы завершенной сборки в разделе **Artifacts** скачайте готовый файл **`AnimeTV-debug-apk` (`app-debug.apk`)**.

### Вариант 2: Сборка на компьютере через Android Studio
1. Распакуйте архив и откройте папку в **Android Studio**.
2. Дождитесь завершения синхронизации Gradle (скачивания библиотек).
3. В верхнем меню выберите **Build -> Build Bundle(s) / APK(s) -> Build APK(s)**.
4. Готовый файл появится по пути `app/build/outputs/apk/debug/app-debug.apk`.
